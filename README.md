# Salonera

Düğün salonları için rezervasyon, sözleşme ve ödeme takibi yapan Windows programı.
Aynı salondaki 2–5 bilgisayar, ana bilgisayardaki veriyi ağ üzerinden ortak kullanır.

Uygulama `app/` klasöründedir (ön yüz React, arka yüz Rust / Tauri, veri SQLite).
Kurulum, geliştirme ve test komutları için bkz. [app/README.md](app/README.md).
